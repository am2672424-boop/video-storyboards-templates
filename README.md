# Narrative Storyboard Framework

Standardized Markdown storyboard templates for short-form AI video pipelines.

## Structure
- **Scene 01:** Hook (0-3 sec) - Extreme close-up, fast motion, suspense sound cue.
- **Scene 02:** Context Build (3-15 sec) - Wide cinematic angle, atmospheric lighting.
- **Scene 03:** Climax / Reveal (15-45 sec) - Rapid angle switching, high contrast.
- **Scene 04:** CTA / Outro (45-60 sec) - Brand element, ambient fade-out.
